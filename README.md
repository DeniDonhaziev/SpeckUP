# SpeckUP — Минута речи 2.2

Рабочий MVP русскоязычной платформы для обучения ораторскому искусству.

## Что добавлено

- регистрация и вход учеников;
- безопасное хеширование паролей;
- постоянные сессии через HttpOnly cookie;
- личный кабинет ученика;
- сохранение результатов тренировок;
- рейтинг по реальным очкам и прогрессу;
- уровни, средний балл, серия дней и история попыток;
- вкладка «Домашние задания»;
- отправка ответов учениками;
- админ-панель;
- создание, публикация, скрытие и удаление заданий только администраторами;
- проверка ответов, оценка и комментарий ученику;
- управление ролями и блокировкой пользователей.

Также сохранены все функции первой версии: случайные темы, подготовка, запись голоса, таймер, слова-паразиты, повторы, паузы, темп, структура и ИИ-разбор.

## Что исправлено в версии 2.2

- одиночные разговорные «ну», «вот» и «значит» больше не считаются ошибкой автоматически;
- смысловые фразы вроде «это значит, что» и «устройство нового типа» не попадают в паразиты;
- отмечаются повторяющиеся лишние связки и настоящие звуки заминки;
- подсвечиваются только конкретные найденные места, а не каждое совпадение из словаря;
- вся запись отправляется на расшифровку целиком, живые субтитры служат только предварительным просмотром;
- при остановке микрофона сайт пытается автоматически переподключить его;
- запись сохраняется частями, поэтому уже сказанная речь не пропадает при восстановлении устройства;
- рейтинг не содержит демонстрационных людей и показывает только зарегистрированных учеников.

## Самый простой запуск на Windows

1. Установите Node.js 20 или новее.
2. Распакуйте архив.
3. Дважды нажмите `START_SITE.bat`.
4. Не закрывайте окно сервера. Откроется `http://localhost:3000`.

**Не открывайте `public/index.html` напрямую:** без локального сервера регистрация, вход, база данных и API не работают.

Перед первым запуском выполните `npm install` (нужен для Firebase; без Firebase можно работать только с локальным `database.json`, но `npm install` всё равно рекомендуется).

## Вход администратора

При первом запуске автоматически создаётся администратор:

```text
Email: admin@minute.local
Пароль: Admin123!
```

Перед публикацией в интернете создайте файл `.env` из `.env.example` и обязательно замените `ADMIN_EMAIL` и `ADMIN_PASSWORD`.

Важно: реквизиты из `.env` применяются только при первом создании администратора. Если база уже создана, удалите `data/database.json` для полного сброса тестовых данных либо измените пользователя через админ-панель.

## Где хранятся данные

По умолчанию после первого запуска создаётся локальный файл:

```text
data/database.json
```

В нём сохраняются пользователи, сессии, результаты, задания и ответы. Пароли в открытом виде не сохраняются — используется `scrypt` с индивидуальной солью.

Локальная JSON-база подходит для разработки и одного сервера. Для продакшена с постоянным хранением рекомендуется **Firebase Firestore**.

### Подключение Firebase Firestore

1. Создайте проект на [Firebase Console](https://console.firebase.google.com/).
2. Включите **Cloud Firestore** (режим production).
3. **Project settings → Service accounts → Generate new private key** — скачайте JSON-ключ.
4. Добавьте в `.env` один из вариантов:

**Вариант A — весь JSON одной переменной (удобно для Render):**

```env
DB_BACKEND=firebase
FIREBASE_SERVICE_ACCOUNT={"type":"service_account","project_id":"...","private_key":"-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n","client_email":"firebase-adminsdk-...@....iam.gserviceaccount.com"}
```

**Вариант B — отдельные поля:**

```env
DB_BACKEND=firebase
FIREBASE_PROJECT_ID=your-project-id
FIREBASE_CLIENT_EMAIL=firebase-adminsdk-...@....iam.gserviceaccount.com
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
```

5. Установите зависимости и перезапустите сервер:

```bash
npm install
npm start
```

При старте в консоли появится строка `База данных: Firebase Firestore`.

Если `DB_BACKEND=auto` (по умолчанию), Firebase включается автоматически, когда заданы credentials. Без них используется локальный `database.json`.

Firestore создаёт коллекции: `users`, `sessions`, `results`, `homeworks`, `submissions`. При первом запуске автоматически создаётся администратор и стартовое домашнее задание — как в локальной версии.

Для составного запроса к ответам учеников импортируйте индекс из файла `firestore.indexes.json` в Firebase Console → Firestore → Indexes.

## Как считается рейтинг

- за тренировку начисляется примерно `оценка / 5` очков;
- за проверенное домашнее задание начисляется указанное администратором количество баллов с учётом оценки;
- прогресс сравнивает первые и последние попытки ученика;
- каждые 100 очков повышают уровень;
- в рейтинг попадают только реальные зарегистрированные ученики, включая новых учеников с нулевым результатом.

## Подключение точной расшифровки

Без API-ключа сайт использует живые субтитры Chrome и локальный анализ. Для надёжного распознавания всей записи целиком добавьте API-ключ в локальный файл `.env`. Сам ключ нельзя размещать в архиве или клиентском JavaScript.

Для полной версии:

1. Скопируйте `.env.example`.
2. Переименуйте копию в `.env`.
3. Вставьте ключ после `OPENAI_API_KEY=`.
4. Перезапустите сервер.

## Деплой на Render

В репозитории уже есть `render.yaml` — Blueprint для автоматического развёртывания.

### Быстрый старт

1. Зайдите на [render.com](https://render.com) и войдите через GitHub.
2. **New → Blueprint** → выберите репозиторий `DeniDonhaziev/SpeckUP`.
3. Render создаст Web Service из `render.yaml`.
4. В панели сервиса откройте **Environment** и задайте:
   - `ADMIN_EMAIL` — ваш email администратора;
   - `ADMIN_PASSWORD` — надёжный пароль;
   - `OPENAI_API_KEY` — по желанию, для ИИ-разбора.
5. Нажмите **Deploy**. Через 1–2 минуты сайт будет доступен по адресу вида `https://speckup.onrender.com`.

### Важно для Render

- Сервер слушает `0.0.0.0` и порт из переменной `PORT` — Render подставляет её автоматически.
- Cookies с `Secure` включаются автоматически на Render (HTTPS).
- Проверка здоровья: `GET /health`.
- **Бесплатный план:** данные в `data/database.json` сбрасываются при каждом redeploy. Для постоянного хранения подключите **Firebase Firestore** (см. раздел выше) или **Persistent Disk** (платный Starter) с mount path `/opt/render/project/src/data` и переменной `DATA_DIR=/opt/render/project/src/data`.
- Микрофон в браузере работает только по HTTPS — Render выдаёт его автоматически.

### Ручной деплой (без Blueprint)

1. **New → Web Service** → репозиторий `SpeckUP`.
2. Runtime: **Node**, Build: `npm install`, Start: `npm start`.
3. Health Check Path: `/health`.
4. Добавьте переменные окружения из `.env.example`.

## Перед настоящим запуском

- смените пароль администратора;
- включите HTTPS и задайте `COOKIE_SECURE=true`;
- перенесите данные в Firebase Firestore или PostgreSQL/Supabase;
- добавьте резервное копирование;
- подготовьте политику обработки персональных данных и согласие на обработку аудио.
